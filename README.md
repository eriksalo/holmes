# Sherlock Holmes: a long reading

A long-term project to read the whole Sherlock Holmes canon and work out, from the text alone, what it observes about being human.

No outside criticism or commentary is used. Every claim should trace to lines in the corpus.

## Layout

- `corpus/raw/` — the nine Project Gutenberg plain-text volumes, unmodified (four novels and five story collections).
- `corpus/works/` — the same text split into one file per novel or story, 60 in all, numbered in canonical publication order.
- `notes/` — reading notes, one file per work. Each records what happens, what the work observes about being human (with story and chapter citations), what it teaches, lines worth keeping, and the work's recurring preoccupations.
- `THE-HUMAN-CONDITION.md` — the synthesis: what the canon as a whole observes and what it teaches, written for one reader to digest and argue with.
- `THE-HUMAN-CONDITION.pdf` and `site/` — the same essay as a print-ready PDF and as a web page, published at https://holmes.salo.cloud. `tools/deploy-site.sh` rebuilds and republishes both.

## How to use it

Read the synthesis first. When a claim there seems wrong or too neat, go to the notes for the story, then to the story itself.
